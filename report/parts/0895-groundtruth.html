The ground-truth audit

At a glance · The ground-truth audit

Every chapter derives its ground truth from the corpus rather than from hand annotation, which is the reason to trust it. This part checks whether the derivation is sound. In two chapters it was not: twelve questions scored as unanswerable were answerable from the text the model was given, and four published rates were too high.

How it was tested

ScopeAll nine chapters, every scorer that decides what the correct answer is
MethodCorpus arithmetic only. No model calls, no API spend
The testStructural: does the supplied text carry an explicit subsection heading naming the topic that was supposedly withheld? Code in shared/contamination.py
Re-measurementCases excluded, prompts unchanged, so every run replays from the committed fixtures
Cost$0

What held / What did not

  • KEEP — Every direction in chapters 3 and 9. The corrections all run the same way: the baselines were inflated, so the gap prompt design accounts for is wider than published, not narrower.
  • KEEP — Corpus-derived ground truth as a method. The defect was found by reading the corpus, in an afternoon, at no cost. A hand-annotated set with the same fault would have needed the annotators back.
  • DROP — “Unanswerable by construction” as a phrase. Withholding a section does not withhold a topic. The document decides that, and on real labels it decides against you.
  • DROP — Chapter 5’s range verdict. Plain and capture prompt are level on a corrected denominator.

The one thing to remember

Three times in this project the model was recorded as failing when it was reading the document correctly — the zero-width spaces it was right to ignore, the DEGRADED grade that was the accurate one, and now twelve questions it was right to answer. Every one inflated a failure rate the book then reported. Check what your ground truth calls wrong before you trust what it calls right, because a scorer that is mistaken in the pessimistic direction produces publishable findings and no error message.

Where this is weakest

The contamination test is deliberately narrow — an explicit heading, nothing else — so the excluded set is a floor and the corrected rates are themselves upper bounds. Omeprazole’s over-the-counter label says children under 18 years of age: ask a doctor with no heading above it, and is not caught. The Chapter 5 correction is a single run: identical prompts collapse to one cached fixture, so the five-run spread cannot be recomputed without paying for it again.
